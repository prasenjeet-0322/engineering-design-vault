> **Srikar's Spoken Draft Script:**
> *At Saavik Solutions, while building our international student marketplace EA Overseas, we had to store sensitive PII, including student passport and visa documents. Storing this in plaintext violated data compliance laws. I was assigned to implement a field-level encryption system. The challenge was that I had zero prior experience with AWS KMS or envelope encryption.*
> 
> *To get up to speed quickly, I spent the first two days researching symmetric key cryptography, GCM authenticated encryption, and the envelope encryption model—where data is encrypted locally using a unique data key, and that key is encrypted using a KMS master key. *
> 
> *I built the encryption framework in TypeScript. To prevent the system from calling AWS KMS on every single database transaction—which would add massive network latency—I engineered an in-memory data key cache with a 5-minute TTL. This allowed us to reuse the decrypted data keys for active user sessions safely while keeping database latency overhead below 5 milliseconds.*
> 
> *The system went live within a week and passed all security audits with flying colors. This experience taught me that when upskilling under tight timelines, you must first master the architectural principles before writing code, and always design with performance bottlenecks in mind.*
