# 🛠️ Plugin Architecture (SPI)

### 🧩 Patterns Used
- **ServiceLoader (SPI)**
- **Inversion of Control (IoC)**

### 💡 Why it matters
This is the ultimate "Open-Closed Principle" (OCP) implementation. It shows how to build a core system that is completely decoupled from its extensions, a common requirement for large-scale platforms (like IDEs or Payment Gateways).
