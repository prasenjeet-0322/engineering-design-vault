# 🛠️ Distributed Lock Simulator

### 🧩 Patterns Used
- **Lease Expiration Pattern**
- **Heartbeat Pattern**
- **Concurrency Control**

### 💡 Why it matters
In modern distributed architectures, single-process locks aren't enough. This simulator demonstrates the critical thinking needed for cross-node resource protection, including handling "crash-and-stay-dead" scenarios.
