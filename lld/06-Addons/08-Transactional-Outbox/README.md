### 🧩 Patterns Used
- **Transactional Outbox Pattern**
- **At-Least-Once Delivery**

### 💡 Why it matters
In distributed systems, keeping a database and message broker in sync is a classic "Reliability" challenge. This ensures total consistency even during broker failures.
