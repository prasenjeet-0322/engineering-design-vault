# 🛠️ Advanced Rule Engine

### 🧩 Patterns Used
- **Strategy Pattern**
- **Composite Pattern**
- **Specification Pattern**

### 💡 Why it matters
Most real-world business logic (Promotions, Risk Scoring, Validation) is too complex for simple `if-else` blocks. This demonstrates how to build a composable, testable engine using a Fluent API.
