# 🟢 Level 1: Foundations (Machine Coding)

This level focuses on the absolute basics of object-oriented programming: identifying entities, establishing class relationships, managing state, and applying fundamental SOLID principles.

## 📁 Included Projects

| Project | Core Focus |
| :--- | :--- |
| **[01-tic-tac-toe](./01-tic-tac-toe/)** | 2D Arrays, Game Loop, Strategy Pattern for winning logic. |
| **[02-snake-and-ladder](./02-snake-and-ladder/)** | State Management, Queue for turns, Entity modeling (Board, Cell, Player). |
| **[03-vending-machine](./03-vending-machine/)** | **State Design Pattern**. Managing transitions (CoinInserted -> Dispensing -> NoCoin). |
| **[04-library-management](./04-library-management/)** | Entity Relationships, Searching, fine calculations, Enums. |
| **[05-2048-game](./05-2048-game/)** | Matrix manipulation, random generation, game state tracking. |
| **[06-minesweeper](./06-minesweeper/)** | Graph traversal (BFS/DFS) for revealing empty cells. |
| **[07-parking-lot-basic](./07-parking-lot-basic/)** | Ticket generation, Spot assignment, Enums (VehicleType, SpotType). |
| **[08-splitwise-basic](./08-splitwise-basic/)** | Graph generation, balance simplification, Strategy Pattern (Equal, Exact, Percent). |
