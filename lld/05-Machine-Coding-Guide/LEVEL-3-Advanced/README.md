# 🟠 Level 3: Advanced (Machine Coding)

This level focuses on distributed systems primitives built locally. These problems test your ability to handle severe concurrency, data streaming, and complex architectural orchestrations.

## 📁 Included Projects

| Project | Core Focus |
| :--- | :--- |
| **[01-aws-s3-service](./01-aws-s3-service/)** | Metadata DB vs Block Storage, chunked uploads, checksum validation. |
| **[02-chat-system](./02-chat-system/)** | Observer Pattern, WebSockets/Polling simulation, Thread-safe message queues. |
| **[03-in-memory-message-queue](./03-in-memory-message-queue/)** | Pub/Sub architecture, Consumer Groups, offset tracking, Broker multithreading. |
| **[04-saga-orchestrator](./04-saga-orchestrator/)** | Distributed transactions. Implementing compensating transactions and state rollback. |
| **[05-stock-matching-engine](./05-stock-matching-engine/)** | Extreme low latency. In-memory Order Books, B-Tree/PriorityQueue for price matching. |
