## 🎯 Overview
Comprehensive frontend testing pyramid: Unit Testing with Vitest/Jest, Component Testing with React Testing Library, End-to-End (E2E) Testing with Playwright, Network Mocking with Mock Service Worker (MSW), and Visual Regression Testing.

---

## 🗺️ Curriculum Topics

1. **Unit Testing Architecture:** Vitest, test isolation, mock functions, timers, spies, coverage thresholds.
2. **React Testing Library (RTL):** User-centric testing philosophy, accessible queries (`getByRole`), asynchronous assertions (`waitFor`, `findBy`).
3. **Mock Service Worker (MSW):** Intercepting network requests at the Service Worker level, REST & GraphQL mock handlers.
4. **End-to-End (E2E) with Playwright:** Cross-browser automation, page object models, fixture architecture, network mocking in E2E.
5. **Visual Regression Testing:** Chromatic, Playwright screenshot diffing, Percy, pixel thresholds.
