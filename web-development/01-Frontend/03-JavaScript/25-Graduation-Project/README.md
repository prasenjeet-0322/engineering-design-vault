## 🎯 Capstone Objectives
Build a production-grade Vanilla JavaScript application demonstrating mastery over:
- State Management & Reactivity (Observable Store / Pub-Sub architecture).
- Component / Module architecture using native ES Modules.
- Non-blocking async data synchronization (`fetch`, `AbortController`, caching).
- Resilient DOM manipulation with zero layout thrashing (`DocumentFragment`, event delegation).
- Memory safety with zero memory leaks (clean listener lifecycle, WeakMap caches).
- Zero external runtime libraries or frameworks.
