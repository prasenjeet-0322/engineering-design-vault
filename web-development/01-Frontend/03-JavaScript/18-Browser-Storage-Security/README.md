## 🎯 Learning Objectives
- `localStorage` vs `sessionStorage` vs `IndexedDB` vs Cookies (Storage limits, lifecycle, synchronous blocking nature).
- Secure Cookie flags: `HttpOnly`, `Secure`, `SameSite=Strict/Lax`.
- Data serialization traps with `JSON.stringify()` (dates, undefined, circular references).
- Security hygiene: Cross-Site Scripting (XSS), token storage risks, and safe storage wrapper implementations.
