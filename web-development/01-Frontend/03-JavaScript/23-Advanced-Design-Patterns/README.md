## 🎯 Learning Objectives
- The Module Pattern (IIFE & ESM encapsulation).
- The Factory Pattern (Object instantiations without `new`).
- The Observer & Pub/Sub Patterns (Decoupled event-driven state architecture).
- The Strategy Pattern (Replacing massive `switch`/`if-else` branches).
- The Decorator / Middleware Pattern.
- Rate-Limiting Primitives: Deep implementation of Debounce vs Throttle (Leading vs Trailing edges).
- Function Memoization and LRU Cache Architecture.
