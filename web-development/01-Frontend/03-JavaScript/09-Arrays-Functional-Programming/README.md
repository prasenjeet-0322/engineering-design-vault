## 🎯 Learning Objectives
- Immutable array transformations (`map`, `filter`, `reduce`, `flatMap`, `toSorted`, `toReversed`).
- Non-mutating vs mutating array methods (the `splice` / `push` / `sort` in-place mutation trap).
- Writing declarative data pipelines and method chaining.
- Transducers, memoized selectors, and algorithmic efficiency ($O(N)$ vs $O(N^2)$).
