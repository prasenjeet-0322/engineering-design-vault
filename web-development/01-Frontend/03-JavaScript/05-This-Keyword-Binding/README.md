## 🎯 Learning Objectives
- The 4 Rules of `this` Binding: Default Binding, Implicit Binding, Explicit Binding, and `new` Binding.
- Explicit Binding Methods: `Function.prototype.call()`, `apply()`, and `bind()`.
- Arrow functions and Lexical `this` (ignoring `call`/`apply`/`bind`).
- Method extraction loss and React event handler binding.
- Predicting the runtime value of `this` deterministically across any call site.
