## 🎯 Overview
Engineering enterprise-grade form workflows: Uncontrolled vs Controlled inputs, Schema Validation (Zod, Yup), Multi-step Wizards, Finite State Machines (XState), Dynamic Field Arrays, and accessible error handling.

---

## 🗺️ Curriculum Topics

1. **React Hook Form Architecture:** Uncontrolled ref-based performance, `useForm`, `useController`, `useFieldArray`.
2. **Schema Validation with Zod:** Type inference (`z.infer<typeof Schema>`), custom refinements, asynchronous validation rules.
3. **Finite State Machines (XState):** Deterministic UI states, transitions, guards, actors, avoiding boolean explosion (`isLoading`, `isError`, `isSuccess`).
4. **Multi-Step Form Wizards:** Persistent wizard state, step validation barriers, browser history sync.
5. **Complex UI Controls:** Drag-and-drop interfaces (`@dnd-kit`), accessible date pickers, rich text editors, virtualized lists.
