## 🎯 Overview
Designing modular, maintainable frontend codebases: Feature-Sliced Design (FSD), Atomic Design, Design Token pipelines (Style Dictionary), Compound Component Patterns, Headless UI primitives, and Monorepo integration foundations.

---

## 🗺️ Curriculum Topics

1. **Architectural Methodologies:** Feature-Sliced Design (App, Pages, Widgets, Features, Entities, Shared), Clean Architecture on Frontend.
2. **Design Tokens & Theme Pipelines:** Design token taxonomy (Global, Semantic, Component tokens), Style Dictionary, CSS Variables integration.
3. **Compound Components & Headless UI:** Compound component pattern (`Select.Root`, `Select.Trigger`, `Select.Item`), Radix UI / Ark UI integration.
4. **Package & Library Boundaries:** Designing standalone UI packages, tree-shaking exports, bundle analysis.
5. **Storybook & Documentation Workflows:** Component isolation, visual regression testing, documentation generation, interaction tests.
