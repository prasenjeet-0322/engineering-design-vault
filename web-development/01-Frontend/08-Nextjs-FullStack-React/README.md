## 🎯 Overview
Enterprise full-stack React with Next.js (App Router): React Server Components (RSC), Server Actions, Streaming SSR, Route Handlers, Caching Layers (Data Cache, Request Memoization, Full Route Cache), Middleware, and Auth.

---

## 🗺️ Curriculum Topics

1. **App Router Architecture:** File-system routing, nested layouts (`layout.tsx`, `template.tsx`), parallel routes, intercepting routes.
2. **React Server Components (RSC):** Server vs Client Component boundary (`'use client'`), serialization boundaries, zero-bundle-size server libraries.
3. **Server Actions & Mutations:** Form actions (`'use server'`), optimistic updates (`useOptimistic`), pending states (`useFormStatus`).
4. **Caching & Revalidation:** Fetch cache, `revalidatePath`, `revalidateTag`, `unstable_cache`, Route Segment Config.
5. **Middleware & Security:** Edge middleware, JWT verification, session cookies, route protection, CSRF headers.
