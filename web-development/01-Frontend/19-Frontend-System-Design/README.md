## 🎯 Overview
Staff and Principal-level Frontend System Design: Radio communication, Micro-frontends (Module Federation), Offline-First Architecture, Real-Time Collaboration (CRDTs/Operational Transformation), Technical RFC Authoring, and Architectural Decision Records (ADRs).

---

## 🗺️ Curriculum Topics

1. **System Design Framework:** Requirements clarification (Functional/Non-Functional), High-level architecture, Data models, Component contracts, Scale/Edge cases.
2. **Micro-Frontends & Module Federation:** Webpack/Rspack Module Federation, Isolated deployment lifecycles, Shared dependency singletons.
3. **Offline-First & Local-First Architectures:** Service Worker caching strategies, IndexedDB local stores, CRDTs (Yjs, Automerge) for collaborative syncing.
4. **Real-Time Collaborative UIs:** WebSockets, SSE, optimistic concurrency, conflict resolution algorithms.
5. **Technical RFC & ADR Writing:** Writing enterprise architectural decision records, trade-off analysis matrices, engineering RFC proposals.
