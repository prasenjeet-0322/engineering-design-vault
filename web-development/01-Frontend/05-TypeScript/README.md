## 🎯 Overview
Master TypeScript's structural type system, advanced generics, conditional types, template literal types, AST type manipulation, compiler configurations, and ambient declarations.

---

## 🗺️ Curriculum Topics

1. **Type System Fundamentals:** Structural subtyping, nominal type simulation (branding), widening, narrowing, exhaustiveness checking.
2. **Advanced Generics & Constraints:** Type parameters, `extends` constraints, default generic arguments, generic factory patterns.
3. **Conditional & Mapped Types:** `infer` keyword, distributive conditional types, `keyof`, `typeof`, template literal types.
4. **Utility Types Deep Dive:** `Partial`, `Required`, `Readonly`, `Pick`, `Omit`, `Record`, `Exclude`, `Extract`, `NonNullable`, `ReturnType`, `Parameters`.
5. **Enterprise Configuration & Monorepo Paths:** `tsconfig.json` inheritance, Project References, path aliases, declaration maps (`.d.ts`).
