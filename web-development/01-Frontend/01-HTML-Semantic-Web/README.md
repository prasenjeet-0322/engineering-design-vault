## 🎯 Overview
Semantic HTML forms the structural and accessibility foundation of the entire Web Platform. This module focuses on accessible DOM element selection, SEO metadata optimization, document outline algorithms, and media optimization for the Critical Rendering Path.

---

## 🗺️ Curriculum Topics

1. **Semantic Elements & Document Hierarchy:** `<main>`, `<nav>`, `<article>`, `<section>`, `<aside>`, `<header>`, `<footer>`.
2. **Metadata & Head Optimization:** OpenGraph tags, JSON-LD structured data, Twitter cards, viewport configuration, canonical links.
3. **Media Optimization:** Responsive images (`<picture>`, `srcset`, `sizes`), modern formats (AVIF, WebP), lazy loading.
4. **Form Controls & Accessibility Foundations:** Native input types, form validation attributes, label-to-input association.
5. **Critical Rendering Path Foundations:** HTML parser streaming, script loading strategies (`defer`, `async`, `type="module"`).
