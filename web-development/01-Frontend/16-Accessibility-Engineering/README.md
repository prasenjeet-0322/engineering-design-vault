# Level 16: Accessibility Engineering (a11y)

## 🎯 Overview
Building inclusive, compliant web experiences adhering to WCAG 2.2 AAA standards: Accessible Object Model (AOM), ARIA roles and live regions, Keyboard focus traps, screen reader testing (NVDA/VoiceOver), and automated a11y auditing.

---

## 🗺️ Curriculum Topics

1. **WCAG 2.2 Core Principles:** Perceivable, Operable, Understandable, Robust (POUR); Level A, AA, AAA compliance criteria.
2. **Accessible Tree & Screen Readers:** Accessibility tree mapping, VoiceOver / NVDA screen reader navigation patterns.
3. **WAI-ARIA Deep Dive:** ARIA roles, states (`aria-expanded`, `aria-selected`), properties (`aria-haspopup`), live regions (`aria-live="polite"`).
4. **Keyboard Navigation & Focus Management:** Focus traps (`focus-trap-react`), skip links, roving tabindex pattern, modal focus restoration.
5. **Color, Contrast & Motion:** Contrast ratios (4.5:1 / 7:1), `prefers-reduced-motion`, `prefers-color-scheme`, dark mode a11y.
