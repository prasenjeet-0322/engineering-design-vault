## 🎯 Overview
Advanced React 18/19 concepts: Concurrent Rendering, `Suspense`, `useTransition`, `useDeferredValue`, Custom Hooks architecture, Profiler API, and memory optimization.

## 🗺️ Curriculum Topics

1. **Concurrent React & Lane Priority:** Interruptible rendering, `startTransition`, `useTransition`, priority lane bitmasks.
2. **Suspense & Streaming UI:** Data fetching with Suspense, error boundaries, streaming fallback states.
3. **Custom Hook Design:** State synchronization, hook composition, event listener abstraction, reusable lifecycle hooks.
4. **Performance Profiling & Memoization:** `React.memo`, `useMemo`, `useCallback`, React DevTools Profiler, flame graphs.
5. **Advanced Escape Hatches:** `useRef`, `useImperativeHandle`, `useSyncExternalStore`, `useInsertionEffect`.
