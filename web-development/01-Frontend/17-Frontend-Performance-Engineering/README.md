## 🎯 Overview
Mastering web performance optimization: Core Web Vitals (LCP, INP, CLS), Bundle Optimization (Code Splitting, Tree Shaking), Resource Hints (`preload`, `preconnect`), Image Pipelines, Memory Profiling, and Performance budgets.

---

## 🗺️ Curriculum Topics

1. **Core Web Vitals Metrics:** Largest Contentful Paint (LCP), Interaction to Next Paint (INP), Cumulative Layout Shift (CLS), Time to First Byte (TTFB).
2. **Bundle Optimization & Code Splitting:** Dynamic imports (`import()`), Route-based splitting, Rollup visualizer, tree-shaking dead code elimination.
3. **Asset & Resource Loading:** Priority hints (`fetchpriority="high"`), `preload`, `preconnect`, font display strategies (`font-display: swap`).
4. **Memory Profiling & Runtime Performance:** Chrome DevTools Memory Heap snapshots, Allocation timelines, identifying memory leaks in SPAs.
5. **Rendering & Compositing Optimization:** Minimizing layout thrashing, virtualizing large datasets (`@tanstack/react-virtual`), CSS containment (`contain`).
