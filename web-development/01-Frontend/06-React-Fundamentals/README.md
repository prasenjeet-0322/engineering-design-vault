## 🎯 Overview
Comprehensive foundation of React 18/19 architecture: JSX compilation, Fiber reconciliation tree, render passes vs commit phase, Hook rules, unidirectional dataflow, and component lifecycle mechanics.

---

## 🗺️ Curriculum Topics

1. **JSX & React Element Factory:** `react/jsx-runtime`, Virtual DOM representation, `React.createElement`.
2. **Fiber Architecture & Reconciliation:** Fiber node tree, double-buffering (`current` vs `workInProgress`), reconciliation heuristic diffing algorithm.
3. **Component State & Lifecycle:** `useState`, `useReducer`, state queues, batching mechanics.
4. **Side Effects & DOM Synchronization:** `useEffect`, `useLayoutEffect`, cleanup functions, effect execution order.
5. **Context API & Prop Drilling:** `createContext`, `useContext`, context re-render propagation, provider nesting patterns.
