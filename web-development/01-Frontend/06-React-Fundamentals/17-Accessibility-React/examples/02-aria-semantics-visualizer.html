The 4 Fundamental ARIA Categories

Pillar 01
ROLE ("What is it?")
Defines widget type or structural landmark (e.g. button, dialog, tab).
Pillar 02
STATE ("What condition?")
Dynamic condition that mutates across lifecycle (e.g. aria-expanded, aria-pressed, aria-checked).
Pillar 03
PROPERTY ("Characteristics?")
Defines structural traits, essential flags or modalities (e.g. aria-haspopup, aria-modal).
Pillar 04
RELATIONSHIP ("Connections?")
Establishes semantic bridges across disparate DOM nodes (e.g. aria-controls, aria-labelledby, aria-describedby).
