## 🎯 Overview
Deep dive into browser execution architecture, rendering pipelines, memory layout, browser storage engines, networking layers, and multi-threaded Web Workers.

---

## 🗺️ Curriculum Topics

1. **The Critical Rendering Path:** HTML/CSS parsing, DOM & CSSOM tree generation, Render Tree, Layout (Reflow), Paint, Compositing.
2. **GPU Acceleration & Layers:** Hardware compositing layers, `will-change`, `transform3d`, subpixel anti-aliasing.
3. **Browser Storage Engines:** `localStorage`, `sessionStorage`, `IndexedDB`, Cache API, Storage Quota management.
4. **Web Workers & Multi-Threading:** Dedicated Workers, Shared Workers, Service Workers, `postMessage`, `Transferable` ArrayBuffers.
5. **Network Layer & Protocols:** HTTP/2 multiplexing, HTTP/3 QUIC, WebSocket bidirectional streaming, Server-Sent Events (SSE).
