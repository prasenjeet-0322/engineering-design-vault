# 📚 Senior Engineer Web Development Vault

Welcome to the **Web Development Knowledge Base**. This is not just a collection of syntax notes, but an **Engineering & Problem-Solving Framework** designed to bridge the gap between frontend fundamentals, backend scaling, and system design. 

This vault follows a strict, layered learning methodology to transition from "knowing how to write code" to "knowing *why* and *when* to write it."

---

## 🏗️ Vault Architecture

This module is split into foundational tiers, moving from client-side UI engineering up to full-stack architectures and deployments.

### 1. [How to Use This Repository](./00-How-To-Use-This-Repository/)
*Start here. This folder dictates how you should study, revise, and debug.*
- [Learning Methodology](./00-How-To-Use-This-Repository/Learning-Methodology.md): The 3-Level Engineering Framework.
- [Revision Strategy](./00-How-To-Use-This-Repository/Revision-Strategy.md): Active recall and engineering tradeoffs.
- [Problem-Solving Framework](./00-How-To-Use-This-Repository/Problem-Solving-Framework.md): Debugging and system thinking.
- [Master Prompt 1 — KPI Documentation Generator](./00-How-To-Use-This-Repository/Master-Prompt-1-Documentation-Generator.md): AI agent instructions for generating documentation.
- [Master Prompt 2 — Validator & Controlled Fixer](./00-How-To-Use-This-Repository/Master-Prompt-2-Validator-Fixer.md): AI agent instructions for source fidelity verification and mastery auditing.

### 2. [Frontend Engineering](./01-Frontend/)
*Mastering the Client Side: from the Critical Rendering Path to Complex React State Management.*
- **HTML/CSS:** Architecture, layouts (Flexbox/Grid), and performance.
- **JavaScript/TypeScript:** Internal engines, event loops, and typing systems.
- **Frameworks:** React/Vue/Angular paradigms and rendering lifecycle.

### 3. [Backend Engineering](./02-Backend/)
*Server Architectures, APIs, and Data Management.*
- **Servers:** Node.js/Express internals and multithreading.
- **APIs:** REST, GraphQL, gRPC, and WebSockets.
- **Data & Caching:** SQL vs NoSQL, Redis, ORMs, and query optimization.

### 4. [Full-Stack Architecture](./03-Full-Stack/)
*Bridging the gap between the Client and Server.*
- **Rendering Patterns:** SSR, SSG, ISR with Next.js/Nuxt.
- **Architecture:** Monorepos (Turborepo), Micro-frontends.
- **DevOps:** CI/CD pipelines, Docker, and deployment patterns (Vercel/AWS).

## 🎯 The Philosophy

> **"Don't memorize APIs. Understand the problems they solve."**

Every topic inside this vault aims to answer three core questions:
1. What problem does this technology solve?
2. When should I use it (and when should I avoid it)?
3. How does it fail in production, and how do I debug it?
